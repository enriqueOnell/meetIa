# AGENTS.md — MeetingAI MVP
## Proyecto
Aplicación web (MVP) para transcripción y resumen de reuniones usando React, Vite, Express, Jitsi IFrame API y LLMs (DeepSeek o Gemma local).
## Comandos
- Frontend: `cd client && npm run dev`
- Backend: `cd server && npm run dev`
## Reglas
- Lee `docs/constitution.md` y `specs/001-meetingai-mvp/spec.md` antes de codificar.
- Prohibido usar el SDK de OpenAI. Usa fetch nativo.
